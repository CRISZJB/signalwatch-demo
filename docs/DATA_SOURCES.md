# 数据来源说明

## 当前实现

| 数据类型 | 来源 | 标记 | 说明 |
|----------|------|------|------|
| 股票/指数报价 | `src/lib/market-data.ts` | `SIMULATED` | 基于基准价的轻微随机游走 |
| 热度 | 同上 | `SIMULATED` | 0–100 模拟热度 |
| 事件 | 同上 | `SIMULATED` | 固定演示公告 |
| 日历 | 同上 | `SIMULATED` | 未来 N 天财报/解禁窗口 |
| 任务/预警/日志 | SQLite (`prisma/dev.db`) | 真实持久化 | 本地数据库 |

界面顶部徽章与行情页均标注「SIMULATED 模拟」，**不得称为实时行情**。

## 故障注入（演示降级）

在「模拟行情」页可切换：

- `none`：正常
- `timeout`：模拟接口超时
- `stale`：模拟数据过期
- `conflict`：模拟多源冲突

也可覆盖某标的模拟价格，便于演示触发（仍标记 SIMULATED）。

## 题目中的可用数据源（未接入）

题目允许使用：

- 扶摇：股票/指数行情、财务、估值、交易日历、指数成分、特色数据
- iFinD MCP：公告、资讯、期货/商品、事件与日历

接入方式建议：实现相同 `MarketQuote` / `MarketEvent` / `CalendarItem` 接口，替换 `buildEvalContext()`，保留 `source: "LIVE"` 标记。

## 合规

关键数字与结论均可追溯到：

1. 模拟数据生成逻辑，或
2. 数据库中的执行快照与预警记录

不编造无来源的统计结论。
