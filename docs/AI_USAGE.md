# AI 使用与验证记录

## AI 在本项目中的角色

1. **辅助实现**：生成 Next.js / Prisma / 规则引擎骨架与中文 UI
2. **文档起草**：README 与 docs 初稿
3. **测试用例**：Vitest 覆盖解析与引擎主路径

**不在运行时调用外部大模型 API。**  
自然语言解析为本地确定性规则（`nl-parser.ts`），保证可测试、可复现、无密钥依赖。

## 验证方式

| 验证项 | 方法 |
|--------|------|
| 解析正确性 | `npm run test` 中 `nl-parser.test.ts` |
| 触发/未触发 | `rule-engine.test.ts` + 页面「立即执行」 |
| 持久化 | 创建任务后刷新页面，数据仍在 |
| 降级 | 模拟行情页切换 timeout/stale 后执行任务 |
| 去重冷却 | 连续执行同一触发任务，查看 SKIPPED / 抑制预警 |
| 版本 | 任务详情改规则保存，版本号递增 |

## 人工复核要点

- 不把模拟行情说成实时
- 不把解析器包装成「在线 AI 决策」
- 演示中展示执行日志中的解释文案

## 开发时间线（摘要）

- 从空目录初始化 Next.js 项目
- 实现 Schema、引擎、API、UI、测试与文档
- 本地启动并跑通主链路
