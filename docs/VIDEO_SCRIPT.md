# 演示视频脚本（60–180 秒）

## 建议时长：约 120 秒

### 0:00–0:15 开场

- 打开总览页，指出「SIMULATED 模拟」徽章
- 一句话：自然语言 → 可编辑规则 → 可调度监控 → 触发可解释

### 0:15–0:45 创建任务

1. 进入「创建监控」
2. 输入：`贵州茅台跌破1700元提醒我`
3. 点击「解析规则」，展示结构化 JSON
4. 略改冷却时间，点击「保存到数据库并启动」
5. 跳转到任务详情，确认已写入

### 0:45–1:15 触发与解释

1. 打开「模拟行情」，将 600519 覆盖为 1650
2. 回任务详情点「立即执行」
3. 展示结果 TRIGGERED 与解释文案
4. 再点一次，展示冷却/去重抑制

### 1:15–1:40 未触发与降级

1. 清除价格覆盖或调高阈值使条件不满足，执行 → NOT_TRIGGERED 有原因
2. 切换「模拟超时」或「模拟过期」，执行 → DEGRADED
3. 恢复正常后再执行 → 任务回到 ACTIVE

### 1:40–2:00 版本与收尾

1. 编辑规则阈值并保存，展示 v2
2. 打开预警中心与执行历史
3. 结束语：关键数字可追溯，模拟数据已标明

## 录制注意

- 不要声称实时行情
- 镜头停留在解释文案与数据库变化结果上
