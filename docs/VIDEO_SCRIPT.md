# 演示视频脚本（目标 120–150 秒｜合规范围 60–180 秒）

正式公网地址：https://signalwatch-sfkf.onrender.com  

录制只在浏览器中操作，**不要**打开终端或改代码。

---

## 录屏前检查（约 1–2 分钟，不计入成片亦可）

1. 打开公网首页，确认能打开（若遇冷启动，等待约 1 分钟加载页）。  
2. 打开「模拟行情」：故障模式点 **正常**；若曾改过覆盖，可先点 **清除覆盖** 再按脚本重设。  
3. 打开「任务」：若已有「贵州茅台跌破 1700」任务且处于冷却/去重窗口，录制时按下方「异常情况话术」解释即可，**不必删库**。  
4. 确认页脚或徽章可见 **SIMULATED**，口播不要说「实时行情」。

---

## 成片时间轴（约 135 秒）

### 0:00–0:15｜开场（总览 `/`）

| 项 | 内容 |
|----|------|
| 点击 | 打开首页 |
| 展示 | SignalWatch 品牌、SIMULATED 徽章、统计卡片 |
| 解说 | 「这是 SignalWatch。用自然语言生成可编辑监控规则，在模拟行情上演示触发与解释。数据全部标记为 SIMULATED，不构成投资建议。」 |
| 预期画面 | 首页加载完成；能看到模拟数据声明 |

### 0:15–0:45｜创建监控（`/create`）

| 项 | 内容 |
|----|------|
| 点击 | 「创建监控」 |
| 操作 | 输入：`贵州茅台跌破1700元提醒我` →「解析规则」→（可选）确认 JSON 含 600519 / 1700 / cross_below →「保存到数据库并启动」 |
| 解说 | 「先把这句话解析成结构化规则，人工可编辑，再保存成任务。」 |
| 预期画面 | 解析出规则；跳到任务详情；状态 ACTIVE |

若库中已有同名任务：可改为打开已有任务详情，口播「任务已创建并持久化，下面直接演示触发」。

### 0:45–1:10｜构造跌破情景（`/market`）

| 项 | 内容 |
|----|------|
| 点击 | 「模拟行情」 |
| 操作 | 代码 `600519`；**当前模拟价格 1650**；**模拟前收盘价 1720** →「覆盖模拟价」 |
| 解说 | 「规则要求真正跌破：前收不低于 1700，现价低于 1700。所以前收设 1720，现价设 1650。」 |
| 预期画面 | 报价表出现前收盘价列；茅台现价 1650、前收 1720、来源 SIMULATED |

### 1:10–1:35｜触发与去重（任务详情）

| 项 | 内容 |
|----|------|
| 点击 | 回到该任务详情 →「立即执行」 |
| 解说 | 「第一次执行应触发预警，解释里能看到现价、前收和阈值。」 |
| 预期画面 | TRIGGERED；预警文案含前收 1720 |
| 再操作 | 再点一次「立即执行」 |
| 解说 | 「相同条件重复执行会被去重抑制，避免刷屏。日志里应出现 DEDUP。」 |
| 预期画面 | SKIPPED + DEDUP，或预警中心出现「去重抑制」 |

**若第一次已是 DEDUP（后台调度已触发过）：**  
口播：「调度可能已提前触发过有效预警，所以现在看到的是去重抑制，这正好说明去重生效。」  
可切到「预警中心」指一下有效预警与带去重标签的记录，然后继续。

### 1:35–1:55｜暂停 / 降级（可选压缩）

| 项 | 内容 |
|----|------|
| 操作 A | 任务「暂停」→「立即执行」→ 应跳过；再「恢复」 |
| 操作 B | 「模拟行情」点「模拟超时」→ 回任务执行 → DEGRADED；再点「正常」后执行恢复 |
| 解说 | 「暂停不会误报；数据超时会降级而不是瞎报。」 |
| 预期画面 | 状态与执行结果文案清晰 |

时间不够时可只做 **降级或暂停之一**。

### 1:55–2:15｜收尾（预警中心 `/alerts`）

| 项 | 内容 |
|----|------|
| 点击 | 「预警中心」 |
| 解说 | 「预警和执行记录都落在数据库。演示使用模拟数据，关键数字可追溯。谢谢。」 |
| 预期画面 | 列表可见触发理由与模拟说明；收束 |

（若总时长已近 150 秒，收尾可压到 10 秒内。）

## 推荐总时长控制

| 段落 | 建议秒数 |
|------|----------|
| 开场 | 15 |
| 创建 / 打开任务 | 30 |
| 行情覆盖 | 25 |
| 触发 + 去重 | 25 |
| 暂停或降级 | 20 |
| 预警中心收尾 | 15 |
| **合计** | **约 130** |

---

## 录制红线

- 不要说「实时行情 / 荐股 / 保证收益」。  
- 不要展示 `.env`、Render 密钥、数据库连接串。  
- 不要在录屏中清空数据库或删除线上任务（除非你有意整理演示账号）。  
- 免费站点休眠导致白屏时：刷新等待冷启动，口播「免费实例冷启动」即可。
