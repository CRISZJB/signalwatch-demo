## 4. 用户如何验证 AI 生成结果

1. **本地自动化**：`npm run test` / `typecheck` / `lint` / `build`（本轮证据见 `evidence/r3-*`）。  
2. **隔离脚本**：去重 `DEDUP`、主链路隔离库（`dedup-evidence.json` 等，r2 轮保留）。  
3. **公网只读核实**（本轮）：`/api/health`、`/api/stats` 快照（见 `r3-05` / `r3-06`）。  
4. **公网人工操作**（用户报告，2026-10-24）：创建任务、触发预警、去重、暂停恢复、超时降级与恢复——详见 `02_测试说明与结果.md`「公网人工验收」。  

AI 生成 ≠ 正确；**以测试、只读接口快照与用户人工验收为准**。

## 5. 合规与能力边界（不得夸大）

- 行情 / 事件 / 日历为 **SIMULATED**，非实时交易数据，不构成投资建议。  
- 未接入真实券商交易系统；未实现邮件 / 企微等推送渠道。  
- 公开演示**不具备**生产级安全与多用户隔离能力声明。  
- Render 免费 Web 可能休眠；免费 PostgreSQL 有到期限制；进程内调度在休眠期间**不能保证**持续执行。  
- 全面合规人工文案审查（C-05）仍为**部分通过**。
