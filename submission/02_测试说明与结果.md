### 关闭浏览器后能否自动调度？

| 场景 | 结论 |
|------|------|
| 仅打开页面依赖 `SchedulerPing` | **否**（关浏览器即停） |
| `next start` + `ENABLE_SERVER_SCHEDULER=1` | **是**（依赖 Node 进程，不依赖浏览器） |
| `scheduler-worker` / 外部 cron 调 API | **是**（依赖 worker/cron 与 API 可达） |
| 正式公网部署定时 | **尚未启用** |
